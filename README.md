# Лабораторная работа 4 — «ВУЗ»

Для сборки нужны CMake 3.16 или новее и компилятор с поддержкой C++17. Команды выполняются в папке с `CMakeLists.txt`.

```powershell
cmake -S . -B build
cmake --build build --config Debug
Push-Location build
ctest -C Debug --output-on-failure
Pop-Location
```

Для MinGW/Ninja запуск `.\build\Lab4.Console.exe`.

Примеры для меню: зачётная книжка `1001`, ФИО «Иванов Иван Иванович», кафедра «Математика», группа «ПИ-101», специальность «Программная инженерия». Для поиска по ФИО каждую часть нужно ввести отдельно. Поиск учитывает регистр.

Лабораторная работа хранит название и двух преподавателей. В список преподавателей группы входят также преподаватели её лабораторных работ. совпадающие ФИО обозначают одного преподавателя.
